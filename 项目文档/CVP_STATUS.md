# CVP evidence status

**CVP eligibility and acceptance: OPEN.** This repository is an independently written defensive experiment. A real local Linux VM and [public Linux CI](https://github.com/dhtfish-98/LandlockFilesystemGate/actions) verify the intended filesystem denial boundary and child inheritance, but the fixture is synthetic and self-owned. These engineering results alone do not establish eligibility or acceptance for any Cyber Verification Program application. They also do not establish a vulnerability or a fix in the referenced Rust Landlock crate.

The CI workflow tests both a checkout and the unpacked tracked-source archive on a real Linux kernel. Review the [workflow](https://github.com/dhtfish-98/LandlockFilesystemGate/actions/workflows/ci.yml) and [Release](https://github.com/dhtfish-98/LandlockFilesystemGate/releases) against the same version commit; a build or upload alone is insufficient publication evidence. The machine receipts are stored in Build or CI artifacts and identify the kernel, ABI, binaries, output and fixture hashes for review.
