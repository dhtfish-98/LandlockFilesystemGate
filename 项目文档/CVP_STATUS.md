# CVP evidence status

**OPEN.** This repository is an independently written defensive experiment. A real local Linux VM verifies the intended filesystem denial boundary and child inheritance, but the fixture is synthetic and self-owned. That engineering result alone does not establish eligibility or acceptance for any Cyber Verification Program application. It also does not establish a vulnerability or a fix in the referenced Rust Landlock crate.

The public repository, GitHub CI results, Release assets and downloaded asset digests remain unverified until they exist and are checked against an exact commit. The machine receipts in Build identify the local kernel, ABI, binaries, output and fixture hashes for review.
